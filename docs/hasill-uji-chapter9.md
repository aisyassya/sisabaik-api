Seluruh pengujian pada Langkah 12 sudah dicoba melalui server lokal Vite dan halaman preview hasil build. Pengujian dilakukan menggunakan Node.js v24.16.0 Data dari komponen utama dikirim ke komponen anak melalui props, sedangkan perubahan dari komponen anak dikirim kembali melalui events. Formulir juga sudah diuji untuk memastikan isian yang tidak valid ditolak, kesalahan rentang harga terdeteksi, dan harga gratis sebesar 0 tetap diterima. Ringkasan pada tampilan pembeli dan penyedia (Rina) berubah mengikuti data. Proses npm run build juga berhasil, dan tampilan sudah diperiksa pada beberapa ukuran layar.
